About SafeRoute AI

SafeRoute AI is a beginner-friendly college mini project designed to suggest safer travel routes for women by considering more than just shortest distance.

The application uses a demonstration Random Forest model trained on synthetic data, a Leaflet map for route visualization, and a simple alert system for high-risk zones. It is meant for educational and demonstration purposes.

System limitations

  • This project does not claim to use verified real-world crime data.
  • Live map routing and live location data may be unavailable in offline or demo mode.
  • Emergency features are clearly marked as demonstration-only unless real SMS or emergency service integration is configured.
  • Safety scores are model-driven estimates from synthetic training examples.
The goal is to build a working project for academic demonstration while keeping all components simple and transparent.
